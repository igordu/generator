# Dataset Generator

A small Java project for generating synthetic datasets with labeled PII and non-PII records for training and evaluating privacy-detection models.

## What it does

It creates a JSONL dataset in this format:

```json
{
  "payload": {
    "user": {
      "name": "John Doe",
      "email": "john.doe@example.com"
    }
  },
  "labels": {
    "contains_pii": true,
    "entities": [
      {
        "type": "PII_PERSON_NAME",
        "value": "John Doe",
        "json_path": "$.user.name"
      },
      {
        "type": "PII_EMAIL",
        "value": "john.doe@example.com",
        "json_path": "$.user.email"
      }
    ]
  }
}
```

The project includes:

- JSON templates with PII markers
- generated and mutated data variations
- plain-text records with and without PII
- balancing between PII and non-PII records
- a training subset and a dataset summary report

## Main classes

### `phd.DataGenerator`

Main class for generating the final dataset.

- loads templates from `generated_templates`
- fills values using the `Faker` library
- writes output to `generated_data/dataset_with_labels.jsonl`
- creates a training subset in `generated_data/dataset_training_5k_v3.jsonl`
- writes distribution summary to `generated_data/dataset_report.txt`

### `phd.TemplateAugmenter`

Generates mutated JSON variations from base templates.

- reads source templates from `src/main/resources/templates`
- creates new JSON variants
- writes files to `generated_templates`
- names files as `PII_*.json` or `NON_PII_*.json`

## Requirements

- Java 19+
- Maven

Check versions:

```bash
java -version
mvn -version
```

## Run the project

### 1) Compile

```bash
mvn clean compile
```

### 2) Generate templates

```bash
mvn exec:java -Dexec.mainClass=phd.TemplateAugmenter
```

This creates new template variations in `generated_templates`.

### 3) Generate the dataset

```bash
mvn exec:java -Dexec.mainClass=phd.DataGenerator
```

This generates:

- `generated_data/dataset_with_labels.jsonl`
- `generated_data/dataset_training_5k_v3.jsonl`
- `generated_data/dataset_report.txt`

## Output format

### JSONL dataset

Each line is a JSON object with `payload` and `labels` fields.

### Report

The report includes:

- number of PII and non-PII records
- total entity count
- distribution by PII type
- overall dataset balance

## Configuration

The main dataset settings are defined in `DataGenerator`:

```java
private static final int TOTAL_RECORDS = 20000;
private static final double PII_RATIO = 0.70;
private static final int TRAINING_SUBSET_SIZE = 5000;
private static final double TRAINING_PII_RATIO = 0.65;
```

This means:

- 20,000 total records
- 70% PII and 30% non-PII
- training subset size of 5,000
- 65% PII and 35% non-PII in the training split

## Notes

This project uses synthetic values generated by `Datafaker` and is intended for research, testing, and development of PII detection systems.

## Typical workflow

1. Put base JSON templates in `src/main/resources/templates`
2. Run `TemplateAugmenter`
3. Check the generated files in `generated_templates`
4. Run `DataGenerator`
5. Review `generated_data/dataset_report.txt`
6. Use `generated_data/dataset_training_5k_v3.jsonl` for model training
